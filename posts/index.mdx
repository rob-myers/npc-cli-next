<Code>
  ```sh title="Spawn, move and remove" showLineNumbers
  # spawn npc at navigable or actable
  spawn npcKey:rob at:$( click 1 )

  # move rob to navigable
  # assuming doors accessible
  move npcKey:rob to:$( click 1 )

  # respawn rob with skeleton key
  spawn npcKey:rob at:$( click 1 ) grant:.

  # move rob via a waypoint
  move npcKey:rob to:$( click 2 )

  # dust to dust
  w npc.remove rob
  ```
</Code>

We finish this quickstart with our underlying motivations.

- __NPCs indistinguishable from human-controlled characters.__
  Permitting a human Game Master makes this possible.<SideNote>
  Can one human act indistinguishably from many humans playing individual parts?</SideNote>
  It also motivates realtime control systems.

- __An in-depth explanation of [Recast-Detour](https://github.com/recastnavigation/recastnavigation).__
  Our NPCs are driven by Recast-Detour running as WASM in a web worker.
  We'll analyse this important C++ library.

- __A generic scripting system for [three.js](https://www.npmjs.com/package/three).__
  We interpret [mvdan-sh](https://github.com/mvdan/sh) syntax trees as JavaScript.
  In production one can run commands.
  In development, shell functions and processes are synced with JS modules.<SideNote>Technically this approach is independent of three.js.</SideNote>

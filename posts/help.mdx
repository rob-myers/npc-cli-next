# Help

## Mobile devices

The same features are available on desktop, mobile and tablet devices.
However it's harder to use a terminal on a mobile.

> <MobileIcon/> The keyboard hogs space,
predictive text is unhelpful,
there are auto-punctuation conflicts,
and usually no arrow keys.

{/* Mobile screens are too small. */}
To make things easier, we provide a terminal _touch menu_ for pasting and submitting commands without a keyboard.
But working with the blog/terminal/world _in tandem_ remains cumbersome on a mobile.
